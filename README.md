## 📖 Overview

This is a complete, modular, interactive HTML E-book built from the "Prep 3 Booklet 2025-2026 First Term". It runs locally in Google Chrome and can be uploaded to GitHub Pages.

## 🚀 How to Run Locally

### Option 1: Direct Open (Simplest)
1. Download or clone this repository
2. Open the `index.html` file directly in **Google Chrome**
3. That's it! No server required.

### Option 2: Using Live Server (VS Code)
1. Install the "Live Server" extension in VS Code
2. Right-click `index.html` and select "Open with Live Server"

## 📤 Uploading to GitHub Pages

1. Create a new GitHub repository
2. Upload all files and folders as-is
3. Go to Settings → Pages
4. Set source to `main` branch, root folder
5. Your site will be published at: `https://yourusername.github.io/repo-name/`
