⏳ Used to / Would

Past habits, states, and adaptation — with visual illustrations and comparisons.

Used to Would Be used to Get used to
🔹 Used to + base form

Used for past habits and states that are no longer true.

Positive
I used to have long hair.
Negative
We didn't use to argue.
Question
Did you use to drink so much?
  • Past habits — actions that happened repeatedly but don't happen now
  • Past states — situations that were true but are no longer true
  • Not used with specific time references (e.g., not "I used to go yesterday")
Habit

"I used to play football when I was young."

State

"She used to live in Cairo."

🔸 Would + base form

Used for past habits (repeated actions) — but NOT for states.

Positive
We would go to the park every Sunday.
  • Past habits — repeated actions in the past
  • NOT used for states (e.g., not "I would have long hair")
  • Nostalgic — often used with memorable feelings
Habit

"When I was a child, I would climb trees."

Habit

"He would always hum while working."

⚠️ Note: "Would" is NOT used for past states.
❌ "I would have long hair." → ✅ "I used to have long hair."

📊 Comparison 1: Used to vs Would

🔹 Used to
  • Past habits — repeated actions
  • Past states — situations
  • Works for habits AND states
"I used to have long hair." (state)
"I used to play tennis." (habit)
🔸 Would
  • Past habits only — repeated actions
  • NOT for states
  • Often used for nostalgic memories
"I would play tennis." (habit)
❌ "I would have long hair."

🔄 Be / Get used to + noun / -ing

✅ Be used to
be + used to + noun / verb-ing

Meaning: Familiar / comfortable with something

"Teachers are used to long working days."
"I'm used to waking up early."
💡 It's normal for me.
🔄 Get used to
get + used to + noun / verb-ing

Meaning: Becoming familiar / adapting to something

"I'm getting used to waking up early."
"She is getting used to the new city."
💡 It's becoming normal for me.
📌 Important: Used to vs Be/Get used to

These are completely different structures with different meanings!

Used to

Past habit / state (no longer true)

"I used to live in Cairo."

(I don't live there now.)

Be / Get used to

Familiar / adapting (present situation)

"I'm used to living in Cairo."

(I live there now and it's normal.)
